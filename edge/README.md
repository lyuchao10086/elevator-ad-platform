# Edge Computing Player (边缘计算播放器)

这是一个基于 C++17 开发的高可靠边缘计算广告播放器。该系统专为电梯广告机、商场大屏等终端设备设计，采用“守护进程 + 播放器进程”的双进程架构，确保系统在无人值守环境下的 7x24 小时稳定运行。

## 核心架构

系统由两个主要部分组成：

1.  **Watchdog (守护进程)**：
    *   **生命周期管理**：负责拉起播放器进程，并在其崩溃或假死时自动重启。
    *   **云端通信**：接管 WebSocket 长连接，处理心跳、日志上报和云端指令。
    *   **本地监控**：通过 UDP 心跳实时监控播放器主循环状态。
    *   **指令中转**：将云端指令（如截图、音量控制）通过本地 IPC 转发给播放器。

2.  **EdgeManager (播放器进程)**：
    *   **音视频引擎**：基于 FFmpeg 解码和 SDL2 渲染。
    *   **智能调度**：支持插播、轮播、定投等多种播放策略。
    *   **数据同步**：定期拉取最新排期与广告元数据，并按排期按需下载素材。
    *   **播放前校验**：每次播放前都执行素材可用性检查（本地存在性 + 下载补齐 + MD5 校验）。
    *   **本地存储**：使用 SQLite 记录分类播放日志。
    *   **兜底机制**：网络异常或无有效排期时，自动循环播放 `resources/ads/default.mp4`。

## 技术栈

*   **语言**: C++17
*   **框架**: FFmpeg, SDL2, SQLite3, cpp-httplib, nlohmann-json
*   **IPC**: UDP (本地心跳与命令中转)

## 快速开始

### 1. 编译项目

```bash
mkdir build
cd build
cmake ..
make
```

### 2. 运行

**推荐方式（守护进程模式）：**
```bash
./build/edge --watchdog ./config.json
```
守护进程会自动拉起播放器，并监控其运行状态。

**调试方式（仅启动播放器）：**
```bash
./build/edge ./config.json
```

## 目录结构

*   `src/`: 源代码文件
    *   `Watchdog.cpp`: 守护进程核心实现
    *   `EdgeManager.cpp`: 播放业务逻辑
    *   `VideoPlayer.cpp`: FFmpeg 播放引擎
    *   `NetworkClient.cpp`: 网络通信模块
*   `include/`: 头文件
*   `resources/`: 存放素材、排期、配置和数据库文件

## 监控与日志

*   **本地心跳**: 播放器每 5s 向守护进程发送一次 UDP 包。
*   **故障自愈**: 
    *   若播放器崩溃，守护进程立即重启。
    *   若播放器假死（30s 无心跳），守护进程强制杀死并重启。
*   **日志记录**: 
    *   **分类记录**: 日志分为 `PLAYBACK` (正常播放), `CRASH` (异常崩溃), `COMMAND` (云端指令执行) 和 `SYSTEM` (系统事件)。
    *   **播放失败细分**: 当素材不可用时，`PLAYBACK` 日志会记录细粒度失败原因，如 `network_failure`、`http_404`、`http_error:<status>`、`md5_mismatch`。
    *   **自动清理**: 为节省存储空间，系统会自动定期清理 5 天前已成功上报云端的历史日志。
    *   故障事件（CRASH, HANG, RESTART）均由守护进程记录并自动上报云端。

## 同步与播放流程

当前边端执行的是“策略驱动素材”的闭环流程：

1. 接收并同步云端排期策略（`schedule`/`schedule_interrupt`/`schedule_timeslot`）。
2. 基于最新策略计算所需素材集合，并向网关按需下载缺失文件。
3. 主循环计算下一条待播素材（插播优先，其次时间段排期，最后兜底素材）。
4. 播放前执行素材可用性检查：
   * 本地文件存在则直接进入播放。
   * 本地缺失则按 `download_retry_count` 重试下载并指数退避（1s、2s、4s...）。
   * 下载成功后进行 MD5 校验，不匹配则删除坏文件并重试。
5. 校验通过后才写入 `playlist` 并开始播放；若校验失败则跳过并写失败日志。

## 远程指令支持

通过云端 WebSocket 下发 JSON 指令：
*   `REBOOT`: 触发播放器软重启。
*   `SNAPSHOT`: 获取当前播放画面截图。
*   `SET_VOLUME`: 远程调节音量。
